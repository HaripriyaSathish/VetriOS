# Figma images (VETRI OS design)

Exported PNG/SVG/WebP images from the VETRI OS Figma file go here. Each
file is picked up by name (extension doesn't matter) via
`src/assets/figmaImages.js`; until a file exists, the page shows a
matching lucide icon / built-in cartoon instead.

| File name (any extension) | Used for |
|---|---|
| `vetri-logo` | Vetri IT Systems logo in the sidebar brand |
| `hero-student` | Cartoon on the Student Dashboard welcome banner |
| `welcome-sparkle` | Small icon next to "Welcome back!" |
| `stat-pending-tasks` | Clipboard icon on the Pending Tasks card |
| `nav-request-access` | Sidebar: Request access |
| `nav-dashboard` | Sidebar: My Dashboard |
| `nav-attendance` | Sidebar: My Attendance |
| `nav-ask-trainer` | Sidebar: Ask Trainer — a message/chat icon, not a trainer figure |
| `nav-assessments` | Sidebar: Assessments |
| `nav-progress` | Sidebar: Progress |
| `nav-assignments` | Sidebar: Assignments |
| `nav-recordings` | Sidebar: Recordings |
| `nav-reports` | Sidebar: Reports |

Export at 2x from Figma (select the layer → Export → PNG 2x).
